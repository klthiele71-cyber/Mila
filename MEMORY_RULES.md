# Mila Memory Rules

## Grundprinzip

Mila soll wichtige Zusammenhänge über Gespräche hinweg verwenden können.
Das Gedächtnis ist jedoch eine kontrollierte Datenkomponente und keine
unkontrollierte Mitschrift aller Gespräche.

## Speicherregeln

- Explizit vom Nutzer festgelegte Informationen dürfen gespeichert werden.
- Für dauerhafte Speicherung sollte später eine klare Klassifizierung erfolgen:
  Fakt, Präferenz, Kontext, Entscheidung oder Aufgabe.
- Unsichere Informationen müssen mit einer niedrigeren Vertrauensbewertung
  versehen oder zur Klärung zurück an den Nutzer gegeben werden.
- Sensible Informationen benötigen später eigene Datenschutz- und
  Berechtigungsregeln.
- Das Gedächtnis darf niemals die Sicherheitsregeln des Mila-Projekts umgehen.
- Eine Erinnerung aus dem Gedächtnis ist keine aktuelle Zustimmung zu einer
  sensiblen Aktion.

## Wichtig für die spätere Version

Dieses Modul ist zunächst absichtlich einfach. Für die produktive Version
brauchen wir zusätzlich:

1. dauerhafte, verschlüsselte Speicherung,
2. Zugriffskontrolle,
3. Änderungs-/Löschkonzept,
4. Herkunft der Information,
5. zeitliche Gültigkeit bzw. Verfallsregeln,
6. Trennung zwischen dauerhaftem Gedächtnis und kurzfristigem Gesprächskontext.

Besonders wichtig:
**Gespeicherte Wünsche oder frühere Zustimmungen dürfen niemals als Ersatz
für die unmittelbar erforderliche Zustimmung bei einer HIGH-Aktion verwendet
werden.**
